# Localmod Keys

React app to **bring your own keys**: llama-server, Ollama, OpenAI, Anthropic, OpenRouter, or a custom URL.

## Install to a folder (Mac + Windows)
Suite → Install → browse a path → Copy files / Download Windows / Download Mac.

## Run
- Windows: `Start-Windows.bat`
- macOS: `Start-macOS.command`

UI: `http://127.0.0.1:1420/keys`
