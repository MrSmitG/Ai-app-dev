# Localmod Code

React app for **agentic coding**: index a project folder, search it, plan and apply multi-file edits.

## Files
All sources live in this repo (`apps/code` plus the shared engine).

## Install to a folder (Mac + Windows)
In Localmod open **Suite → Install**. Browse a file path, then copy files here (or download `Localmod.exe` / `Localmod.dmg` into that folder).

## Run
- Windows: `Start-Windows.bat`
- macOS: `Start-macOS.command`

Then the Code UI is at `http://127.0.0.1:1420/code`.
