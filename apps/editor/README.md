# Localmod Editor

React app to **stay in your editor**: inline edit here, or install the VS Code extension in `apps/keep`.

## Install to a folder (Mac + Windows)
Suite → Install → browse where files should go.

## Run
- Windows: `Start-Windows.bat`
- macOS: `Start-macOS.command`

UI: `http://127.0.0.1:1420/editor`

VS Code: `code --install-extension apps/keep`
