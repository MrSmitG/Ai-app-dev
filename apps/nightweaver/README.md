# Nightweaver

An unseen entity spinning complex webs of code in the background.

Index a project folder, search it, then plan and apply edits across files.

This is a **standalone React app**. Start it by itself — then start the next one when you want.

## Start this app

From the repo root:

```bash
npm run nightweaver
```

- Windows: double-click `Start-Windows.bat`
- macOS: double-click `Start-macOS.command`

Opens `http://127.0.0.1:1422`. The shared engine stays on `127.0.0.1:4781`.

Then start another:

- `npm run blackwhale` → Blackwhale (`:1421`)
- `npm run obsidian` → Obsidian (`:1423`)
- `npm run mako` → Mako (`:1424`)
- `npm run trench` → The Trench (`:1425`)
- `npm run ironmantis` → Ironmantis (`:1426`)
