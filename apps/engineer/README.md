# Localmod Engineer

React app for an **autonomous engineer**: read/write files, run allowlisted CLI, finish multi-step jobs.

## Install to a folder (Mac + Windows)
Suite → Install → pick a file path. Workspace folder is chosen the same way inside the app.

## Run
- Windows: `Start-Windows.bat`
- macOS: `Start-macOS.command`

UI: `http://127.0.0.1:1420/engineer`

VS Code: `code --install-extension apps/hands`
